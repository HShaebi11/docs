Loop is the wire between your inputs and your outputs. You author the two ends — a source that reads from keyboard, gamepad, MIDI, or any device, and a sink that writes to a canvas, DOM element, WebSocket, or anything else — and Loop carries normalized packets between them without rendering a single pixel itself.

## How it works

Loop follows a simple four-step onboarding flow. Once you complete it, every input you add and every output you wire follows the same pattern.

<Steps>
  <Step title="Install">
    Add Loop to your project with your package manager, or drop it straight into a `<script type="module">` tag with no build step required.

    ```bash
    npm install @theinterfaces-lab/loop
    ```
  </Step>
  <Step title="Define a source and a sink">
    Tell Loop where your data comes from (`loop.source`) and where it should go (`loop.sink`). Both carry typed packets — `value`, `frame`, or `data`.

    ```typescript app.ts
    import loop from "@theinterfaces-lab/loop";

    const keyboard = loop.input("keyboard");
    const el = document.getElementById("output");

    const src = loop.source({
      from: "keyboard",
      emits: "data",
      dataType: "text",
      read: () => ({ kind: "data", type: "text", value: keyboard.value }),
    });

    const snk = loop.sink({
      to: "mirror",
      accepts: "data",
      dataType: "text",
      render: (p) => { el.textContent = String(p.value); },
    });
    ```
  </Step>
  <Step title="Connect them in a pipeline">
    Pass your stages to `loop.pipe()`. Loop checks that adjacent stages are packet-compatible at wiring time — mismatched kinds throw before the first frame.

    ```typescript app.ts
    loop.pipe(src, snk).start();
    ```
  </Step>
  <Step title="Register a tick callback">
    Use `loop.tick()` to run any per-frame logic — reading handle values, updating positions, or polling state — synchronized to `requestAnimationFrame`.

    ```typescript app.ts
    const el = document.getElementById("square");
    const dpad = loop.input("dpad");
    let x = 0, y = 0;

    loop.tick(() => {
      x += dpad.value.x * 4;
      y += dpad.value.y * 4;
      el.style.transform = `translate(${x}px, ${y}px)`;
    });
    ```
  </Step>
</Steps>
